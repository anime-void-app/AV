ANIME VOID 16.7 — КАРТА АНИМЕ-ВСЕЛЕННЫХ

Это готовое совмещённое обновление поверх существующего сайта AV.
В архиве изменённые файлы сайта, новая карта и все 6 записей звуков 16.6.
Публикация на GitHub не выполнялась.

КАК УСТАНОВИТЬ
1. Распакуй ZIP.
2. Скопируй его содержимое прямо в корень своего проекта AV — туда, где index.html.
3. Подтверди замену файлов. Папку audio объедини с существующей, не удаляй её.
4. В VS Code: Source Control → Commit → Sync Changes.
5. Дождись публикации GitHub Pages, затем обнови сайт Ctrl+F5.
   Если используешь установленную PWA, полностью закрой её и открой снова после
   первого открытия обновлённого сайта с интернетом.

НЕ очищай данные сайта/localStorage: это не требуется для обновления.
Остальные файлы проекта удалять не нужно. Архив не заменяет весь репозиторий.
Можно заранее сделать резервную копию прогресса через существующий раздел сайта.

ГДЕ КАРТА
• На странице аниме под названием: «Карта вселенной ↗».
• На телефоне: нижняя вкладка «Карта».
• В меню каталога: «Карта вселенных».
• Прямая ссылка после публикации:
  https://anime-void-app.github.io/AV/universe.html

КАК ПОЛЬЗОВАТЬСЯ
Выбери стартовую франшизу или найди аниме по названию/AniList ID.
Нажми на постер или строку списка: откроются сведения, существующий прогресс,
описание AniList (если доступно) и ссылка на страницу аниме.
«Раскрыть связи» добавляет следующий уровень, «Сделать центром карты» переносит
центр на выбранный тайтл. Новые узлы сами себя бесконечно не раскрывают.
Схему можно перетаскивать и масштабировать. На телефоне сначала включён список;
в режиме «Схема» работают два пальца. Есть «К центру» и «Вся карта».
Клавиатура: Tab, Enter; на области схемы — стрелки, +/−, Home/0.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
• Связи AniList НЕ являются автоматическим порядком просмотра или единым каноном.
  Точное направление связи указано в карточке выбранного тайтла.
• Старые переключатели сезонов и гайд по «Моногатари» сохранены.
• На одной карте максимум 60 тайтлов и 24 запроса связей. Для большой франшизы
  выбери новый центр. Отдельные фильтры могут скрывать промежуточные узлы.
• Встроенный снимок: 97 аниме, получен из AniList 30.10.2026. Есть 6 стартовых карт.
  Для новых аниме и актуализации связей нужен доступный AniList.
• «Обновить связи центра» обновляет центральный тайтл, а не всю франшизу за раз.
• Встроенные и ранее сохранённые связи работают без API. Для офлайн-страницы
  сначала открой обновлённый сайт с интернетом. Постеры доступны офлайн после
  загрузки; иначе показывается штатная заглушка.
• Метаданные карты сохраняются отдельно в IndexedDB, максимум 160 записей.
  Карта только читает прогресс: не меняет отметки, статусы и резервные копии.
• Описания AniList могут быть на английском. Русские названия используются из
  существующего словаря сайта, если они в нём есть.
