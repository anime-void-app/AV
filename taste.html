Честная граница сравнения

Совпадение — только один и тот же AniList ID. Разные сезоны не склеиваются, названия не угадываются. Пересечение / объединение выбранных ID — не совместимость людей, не вероятность дружбы и не качество вкуса. Средняя абсолютная разница оценок считается только там, где оба явно указали 1–10; отсутствие оценки не равно нулю.

До100тайтлов на сторону. Черновик живёт только на этой странице и пропадёт при перезагрузке. Сохранение — явная выгрузка отдельного JSON после просмотра точного состава. Он содержит только ID, введённое название и выбранную оценку, без имени, истории, списков или идентификатора аккаунта. Сайт сам ничего не отправляет; перед передачей файла проверьте его и согласие участников. Любая другая вкладка/источник файла может сообщать недостоверные данные.
