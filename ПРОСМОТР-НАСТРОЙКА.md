# ANIME VOID 24.7 — свой плеер, без YouTube

## Что изменено

YouTube iframe, его API, четыре старые видеопривязки и блок «Другие площадки / Где посмотреть» удалены из активного плеера. Рекламный блок четырёх первых серий на главной больше не показывается.

Сделан собственный плеер на HTML5 video:
- прямые MP4;
- HLS: встроенная поддержка браузера либо локальная библиотека hls.js 1.6.15 (MIT);
- воспроизведение/пауза, звук, перемотка и скорость средствами браузерного плеера;
- полноэкранный режим;
- выбор качества при наличии нескольких HLS-уровней;
- выбор настроенного источника/озвучки и подключённых эпизодов;
- сохранение позиции отдельно для каждой медиозаписи и продолжение;
- синхронизация позиций через прежний аккаунтный механизм после его настройки.

## Важное ограничение

**Рабочий источник аниме-серий пока НЕ подключён. Самих серий в архиве нет.**

Реестр `player-sources.js` намеренно пуст. На странице написано «Источник серий ещё не подключён»; пустое видео не выдаётся за доступное аниме. Старые ссылки YouTube не используются даже при открытии старой закладки. Нельзя обещать просмотр аниме без сервера, который действительно отдаёт серии.

Плеер проверен на собственном техническом MP4 и сгенерированном из него HLS-потоке. Эти тестовые материалы НЕ являются аниме, НЕ включены в сайт и НЕ показываются посетителям.

## Как опубликовать обновление

Из полного ZIP откройте папку `САЙТ` и загрузите её содержимое на уровень работающего `index.html` в репозитории AV. Не создавайте ещё одну вложенную папку `САЙТ`. Не удаляйте CNAME.

Для изменения именно плеера нужны:

```
index.html
watch.html
av-player.js
av-player.css
av-player-home.js
player-sources.js
av-safety.js
service-worker.js
vendor/hls.light-1.6.15.min.js
vendor/HLS-JS-LICENSE.txt
```

Сохраните структуру папки `vendor`. `PLAYER-SOURCE-FORMAT.json` — документация, не активный источник. Полное обновление всех файлов предпочтительнее частичной замены. Веб-интерфейс GitHub может ограничивать количество файлов в одной загрузке — загружайте партиями либо используйте GitHub Desktop. Не удаляйте прежние файлы сайта перед загрузкой.

После успешной публикации в Actions перезагрузите страницу с Ctrl+Shift+R. Новая версия service worker: `av-AV-core-v24.31`.

HTTPS-сертификат и DNS эта сборка не исправляет. Не вводите пароли на странице с предупреждением о сертификате. Аккаунты по-прежнему требуют выполнения `АККАУНТЫ-НАСТРОЙКА.md` и прежнего SQL; схема рабочей базы агентом не изменялась.

## Как подключить настоящий источник

Нужен действующий разрешённый HTTPS URL MP4 или HLS `.m3u8`. Для HLS сервер должен отдавать плейлист и сегменты с подходящими CORS-заголовками для вашего домена. Для MP4 нужен корректный MIME и желательно поддержка HTTP Range для перемотки.

`PLAYER-SOURCE-FORMAT.json` показывает поля записи. В нём URL равен null: это не рабочая ссылка и не демо-серия. В `player-sources.js` массив `sources` заполняется только после получения настоящих адресов. Поддерживаемые типы: `mp4` и `hls`. Для каждого эпизода требуется стабильный уникальный `key`; одинаковый файл не следует привязывать к разным аниме.

Плеер не извлекает защищённые потоки с других сайтов, не проксирует их, не обходит возрастные/географические ограничения и не создаёт доступ к чужим сериям. Секретные API-ключи не размещайте в реестре: для защищённого поставщика нужен отдельный сервер, выдающий разрешённый доступ пользователю.

## Сохранность данных

Покупки, каталог, подарки, права, аккаунты и старые отметки просмотра не удалялись. Ручной трекер остаётся в блоке «Мои отметки просмотра». Старые позиции YouTube также не стираются, но старые видеоисточники больше не подключаются.

Позиции хранятся в проверяемом ключе `animeVoidPlaybackV1`. Новые записи имеют ключи `media-...`; старые `yt-...` сохраняются для совместимости. Запуск видео не выдаёт валюту, VIP и подарки. Повреждённый архив позиций не перезаписывается. Само видео не сохраняется в аккаунте и не кэшируется для офлайн-просмотра.
