# ANIME VOID 24.9 — RUTUBE вместо недоступного источника

## Что изменено

После проверки пользователя: AniLiberty в его российской сети работает только с VPN. Поэтому активная интеграция AniLiberty отключена, её рекламные ссылки на главной убраны. Обращений к её API и CDN больше нет. YouTube также не используется.

Для существующей карточки «Торадора!» (anilist-4224) подключён официальный встраиваемый плеер RUTUBE, канал «РуАниме», дубляж Reanimedia, 16+.

На главной ссылка по умолчанию открывает именно серию 4, которую проверил пользователь. Есть выбор только серий 3 и 4. Серии 1–2 не подключены, полный сезон из 25 серий не заявляется доступным. Метаданные серии 2 вернули отказ — она не добавлена. Другие тайтлы не подменяются «Торадорами».

## Что ещё требуется проверить

**Пользователь подтвердил воспроизведение на RUTUBE, а не внутри ANIME VOID.** Это разные проверки. Фактическое встраивание на опубликованном animevoid.ru в российской сети пока не подтверждено.

Сборка использует стандартный официальный iframe `https://rutube.ru/play/embed/<videoId>/`. Если правообладатель, RUTUBE или настройки домена ограничат встраивание, страница покажет сообщение и не будет утверждать, что видео работает. Работа на основном сайте RUTUBE сама по себе не гарантирует разрешение iframe. Географические ограничения сохраняются. Из тестовой среды воспроизведение российского регионального контента не подтверждается.

После публикации откройте ANIME VOID → «Смотреть на сайте» → «Торадора!, серия 4» → «Загрузить серию», затем кнопку воспроизведения внутри RUTUBE. Нужно убедиться, что видео идёт именно внутри ANIME VOID без VPN. Если показан отказ — пришлите его текст или скриншот; не обходите предупреждения и ограничения.

## Свой интерфейс и плеер поставщика

Серии выбираются и просматриваются на странице ANIME VOID, но воспроизведение RUTUBE выполняет его собственный официальный iframe. Качество, звук, рекламные показы и элементы управления поставщика сохраняются. Прямые защищённые HLS-адреса из RUTUBE не извлекаются. Прокси, подмена Origin/Referer, обход региона/возраста и удаление рекламы не используются.

Собственный MP4/HLS-движок сохранён для будущих разрешённых прямых источников, но не выдаётся за способ обойти iframe-условия RUTUBE.

## Публикация

Полный сайт находится в папке `САЙТ` внутри ZIP. Загрузите её содержимое на уровень работающего `index.html` в репозитории AV. Не создавайте ещё одну вложенную папку `САЙТ` и не удаляйте CNAME.

Если уже установлена версия24.8, для этого изменения замените/добавьте из `САЙТ`:

```
index.html
watch.html
player-sources.js
av-source-loader.js
av-rutube-player.js
av-player-home.js
service-worker.js
```

Старые файлы `av-player.css`, `av-safety.js` и папка `vendor` должны оставаться на месте. При полной установке загрузите всё содержимое папки `САЙТ`, сохраняя папки. Дождитесь успешной публикации Actions. Затем Ctrl+Shift+R. Новый service worker: `av-AV-core-v24.33`.

Проблемы HTTPS-сертификата и DNS эта сборка не исправляет. Пока браузер показывает предупреждение о сертификате, пароли вводить нельзя.

## Позиция и сохранность данных

- Встроенный адаптер использует документированный RUTUBE postMessage API. Проверяются и точный origin `https://rutube.ru`, и окно конкретного iframe; сообщения других окон игнорируются.
- Позиция сохраняется только по данным плеера. Рекламное время не записывается вместо времени серии; чужая длительность отклоняется.
- Продолжение отправляется штатной командой поставщика после готовности видео, не во время рекламного ролика.
- Готовность iframe не называется успешным воспроизведением. Ошибки и заглушки поставщика отображаются.
- Ключ позиций прежний: `animeVoidPlaybackV1`; для RUTUBE используется запись `media-rt-<videoId>`.
- Позиции старых источников не удалялись. Покупки, каталог, подарки, права, аккаунты и ручные отметки сохранены.
- Сам запуск плеера не выдаёт очки, VIP или награды. Ручной трекер остаётся доступен и следует выбранному номеру серии.
- Автосинхронизация между устройствами использует прежний механизм аккаунтов и требует корректных SQL/авторизации/HTTPS. Боевая база агентом не менялась.

## Проверки

22 проверки адаптера на имитаторе официального iframe SDK: PASS. Проверены выбор серий, сохранение, продолжение, запрет сообщений с другого origin, игнорирование рекламной шкалы времени, ошибки поставщика, RU/EN и ширины320–1440px. В проверке нет запросов YouTube, AniLiberty и её CDN.

**Это проверка кода адаптера, не подтверждение реального воспроизведения российского контента в iframe.** Единственное уже полученное подтверждение из российской сети — сообщение пользователя о работе серии4 на самом RUTUBE без VPN.

Официальная документация API плеера: https://github.com/rutube/RutubePlayerJSAPI . Реестр источников задаётся явно в `player-sources.js`; произвольные посетительские URL не используются.
