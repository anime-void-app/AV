Собственный плеер MP4/HLS теперь получает серии из публичного API AniLiberty / AniLibria:

| Существующий тайтл сайта | AniList ID | Релиз поставщика | Подключённые серии |
|---|---|---|---|
| Магическая битва, первый сезон | 113415 | 8789 / jujutsu-kaisen | 1–24 |
| Доктор Стоун, первый сезон | 105333 | 8398 / dr-stone | 1–24 |
| Этот глупый свин не понимает мечту девочки-зайки | 101291 | 7462 / seishun-buta-yarou-wa-bunny-girl-senpai-no-yume-wo-minai | 1–13 |

Всего 61 серия. Все три тайтла уже были в каталоге: новые карточки и ID не добавлялись. Русскоязычный источник обозначен в плеере. YouTube, его iframe/API и прежние четыре пробные привязки не возвращены.

Официальная документация API поставщика: https://anilibria.top/api/docs/v1 . Данные релиза: `https://anilibria.top/api/v1/anime/releases/{id}`.

## Что реально проверено

- API вернул полные списки 24 + 24 + 13 эпизодов.
- 61 HLS-плейлист ответил HTTP 200, содержал медиаплейлист и длительность полной серии, не трейлера.
- В браузере через встроенный плеер сайта действительно запущены первые серии всех трёх тайтлов: время воспроизведения увеличивалось, размер видеокадра 1280×720.
- Длительности первых серий: около 1435, 1446 и 1500 секунд.
- Дополнительно проверены вторая серия «Магической битвы», переключение на 480p, сохранение позиции и продолжение после перезагрузки.
- Проверены RU/EN, ширины 320/390/1440 px, отсутствие запросов YouTube и ошибок JavaScript.
- Проверка имитированного отказа поставщика подтвердила: заблокированный релиз не воспроизводится, запасного обхода или подмены серии нет.

**Все 61 серию целиком агент не просматривал.** Проверка URL всех эпизодов и реальное декодирование выбранных эпизодов — разные проверки.

## Важные условия доступности

Это внешний источник, а не видео на вашем сервере. Доступность зависит от поставщика, региона, сети и оператора посетителя. Проверка из тестовой среды не доказывает доступность у каждого оператора РФ. Если API или CDN недоступен у посетителя, сайт покажет ошибку; обойти блокировку этот код не пытается.

Ссылки получаются в браузере посетителя при открытии страницы. В сборку НЕ зашиты HLS-адреса с `countryIso=US` из тестовой сессии. Параметры URL, которые выдаёт поставщик, не удаляются и не изменяются: в том числе региональные и рекламные параметры. Никаких поддельных Origin/Referer, чужих токенов, видеопрокси и обходов ограничений нет.

Код учитывает `is_blocked_by_geo` и `is_blocked_by_copyrights`. При ограничениях источника видео не загружается. Выбранные три релиза помечены самим поставщиком как 16+, не как взрослые. Флаги API описывают состояние сервиса, а не являются отдельным лицензионным договором. Публичное API не заменяет проверку условий поставщика и необходимых прав для коммерческого использования сайта.

## Публикация обновления

Из ZIP откройте папку `САЙТ` и загрузите её содержимое в папку работающего `index.html` в репозитории AV. Не загружайте ZIP как файл сайта и не создавайте ещё одну вложенную папку `САЙТ`. CNAME не удаляйте.

Для изменения просмотра относительно 24.7 необходимо заменить/добавить:

```
index.html
watch.html
player-sources.js
av-source-loader.js
av-player.js
av-player-home.js
service-worker.js
```

Из 24.7 также должны быть опубликованы `av-player.css`, актуальный `av-safety.js` и папка `vendor` с `hls.light-1.6.15.min.js` и лицензией. Проще загрузить всё содержимое папки `САЙТ`, сохраняя вложенные папки. GitHub может ограничивать число файлов за загрузку — при необходимости загружайте партиями или используйте GitHub Desktop.

Дождитесь успешного Actions/deployment. Затем Ctrl+Shift+R. Новый service worker: `av-AV-core-v24.32`.

На главной рядом с каталогом появится «Смотреть на сайте» с тремя тайтлами. В плеере — действующие номера серий и доступные варианты 480p/720p/1080p из API. Неподключённые тайтлы не заменяются другими сериалами.

## Настройки и сохранность

- `player-sources.js`: явные соответствия трёх существующих AniList ID релизам поставщика. Автоматического поиска «похожего названия» нет: проверяются ID, alias и год.
- `av-source-loader.js`: загрузка актуального релиза, проверка ограничений, получение эпизодов и запуск своего плеера.
- `av-player.js`: собственный HTML5/HLS плеер. MSE-браузеры используют локальный hls.js; при отсутствии MSE возможен штатный HLS браузера.
- Состояние просмотра: прежний проверяемый ключ `animeVoidPlaybackV1`, отдельная запись для каждого стабильного ID эпизода.
- Аккаунты, покупки, подарки, права, старые отметки и старые позиции YouTube не удалялись. Сам запуск видео не выдаёт валюту или привилегии.
- Ручной трекер остаётся доступен; при смене серии номер для ручной отметки синхронизируется с плеером.
- Автоматическая синхронизация позиций между устройствами требует ранее настроенных Supabase/SQL/авторизации и HTTPS. Рабочую базу агент не изменял.
- Видео не сохраняется в аккаунте, не скачивается на сервер сайта и не кэшируется для офлайн-просмотра.

Секретные ключи для этого публичного API не требуются. Сертификат animevoid.ru и DNS данное обновление не исправляет: до устранения предупреждения HTTPS пароли вводить нельзя.
