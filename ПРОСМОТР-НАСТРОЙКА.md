## Важный статус проверки

**Реальное воспроизведение этих четырёх видео в тестовой среде НЕ подтверждено.**

В этой среде ранее и обычный демонстрационный ролик YouTube, и проверочный эпизод другого официального канала завершились ошибкой 150. Проверки watch-страниц выбранных русских видео были ограничены YouTube ответом HTTP 429; лимит не обходился. Наличие видео в официальном канале и его полная длительность не доказывают разрешение встраивания и доступность в конкретной стране или на animevoid.ru.

Встроенный плеер использует обычный официальный API без обходов. Если издатель или YouTube отклоняет воспроизведение, страница показывает отказ, а не ложное сообщение об успешном просмотре. Региональные ограничения, возрастные требования, ограничения домена и недоступность самого YouTube сохраняются. Сборка не гарантирует, что эти ограничения отсутствуют у посетителя.

Для окончательной проверки после публикации откройте сайт в обычном браузере, нажмите первую серию и убедитесь, что идёт само видео, работают звук, перемотка и повторное продолжение. Если показано «Видео недоступно», такой источник нельзя считать рабочим для этого посетителя. Не используйте обходы запрета поставщика.

## Позиция просмотра и сохранность данных

- Сохраняется фактическая позиция, полученная от API плеера; отдельная запись для каждого video ID.
- При повторном открытии — предложение продолжить с сохранённого времени. Есть кнопка «С начала».
- Позиция хранится в `animeVoidPlaybackV1`. Этот ключ включён в проверяемые резервные данные аккаунта.
- После входа автоматическая синхронизация использует существующий механизм 24.5. Она требует правильно настроенных Supabase SQL, авторизации и HTTPS. Рабочая база и настройки Google агентом не изменялись.
- Сам запуск плеера не выдаёт валюту, VIP, подарки или награды и не подделывает старые отметки просмотра.
- Прежний ручной трекер доступен в раскрывающемся блоке «Мои отметки просмотра».
- Повреждённый существующий архив позиций не перезаписывается. Ошибки хранилища отображаются.
- Покупки, каталог, арт, подарки и права не сбрасывались.

## Публикация

1. Загрузите содержимое папки `САЙТ` из полного архива в корень вашего размещения.
2. Откройте сайт по правильному HTTPS-домену. Проблемы сертификата и DNS эта сборка сама не исправляет.
3. Дождитесь обновления service worker до `av-AV-core-v24.30`; при необходимости перезагрузите страницу.
4. В каталоге выберите один из четырёх источников и нажмите «Смотреть серию».
5. Для автосохранения между устройствами выполните прежнюю инструкцию `АККАУНТЫ-НАСТРОЙКА.md`, если она ещё не выполнена.

Секретные ключи, OAuth client secret или Supabase service-role key в HTML добавлять нельзя. YouTube API key для этого iframe-плеера не требуется. Плеер не загружает видео на ваш сервер и не скрывает рекламу/управление поставщика. Сами серии не кэшируются для офлайн-просмотра.

## Где менять источники

`player-sources.js` — явный реестр привязок к существующим anime ID. Ввод произвольного URL посетителем не используется. Для нового видео сначала проверьте полную серию, язык, соответствие тайтлу/эпизоду, разрешение встраивания и фактический запуск. Не увеличивайте счётчик подключённых серий без реальных проверенных ссылок.
