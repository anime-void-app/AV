# ANIME VOID V70 — исходные файлы, качество и размер

## Готово

На `watch.html` появилась панель выбора реальных доступных файлов: **Оригинал**, другие разрешённые варианты качества (например, 1080p/720p), формат и размер. Оригинал предлагается первым. Размер выводится только из точного значения `bytes`; если оно не предоставлено, написано «Размер неизвестен».

Загрузка идёт напрямую с сервера правообладателя, **без перекодирования, скринкаста, HLS-экстракции или DRM-обхода**. На внешнем домене браузер может открыть файл в новой вкладке, если сервер не отдаёт `Content-Disposition: attachment`. Для гарантированного скачивания администратор источника должен настроить заголовки HTTP.

## Как подключить реальную серию

Редактируй корневой файл `licensed-downloads.json`. Изначально `sources` пуст — реальные права и файлы не предоставлены. Пример ТОЛЬКО ФОРМАТА (в репозитории нет фиктивных ссылок):

```json
{
  "version": 1,
  "sources": [
    {
      "id": "licensed-cdn",
      "label": "Партнёрский источник",
      "animeId": "anilist-12345",
      "allowOriginalDownload": true,
      "episodes": [
        {
          "number": 1,
          "files": [
            {
              "licensed": true,
              "original": true,
              "format": "mkv",
              "url": "https://your-authorized-cdn.example/episode-1-original.mkv",
              "filename": "Episode-01-Original.mkv",
              "bytes": 2147483648
            },
            {
              "licensed": true,
              "original": false,
              "quality": "1080p",
              "format": "mp4",
              "url": "https://your-authorized-cdn.example/episode-1-1080p.mp4",
              "filename": "Episode-01-1080p.mp4",
              "bytes": 800000000
            }
          ]
        }
      ]
    }
  ]
}
```

- `animeId` должен совпадать с ID в `watch.html?id=...` и каталогом.
- Каждая серия имеет `number` и `files`. `licensed: true` и `allowOriginalDownload: true` ставить **только после подтверждения прав на распространение и скачивание**. Проверка прав на клиенте — не механизм безопасности сервера.
- `original: true` ставить только для фактического исходника. Иначе `original: false` и `quality` из `4320p, 2160p, 1440p, 1080p, 720p, 576p, 480p, 360p`.
- `bytes` — реальный размер файла в байтах. Если неизвестен, убрать поле; **не угадывать**.
- Допустимые контейнеры: MP4, MKV, WebM, MOV, M4V, AVI.
- Ссылки на HTTPS (или тот же origin в dev). Не кладите в публичный статический каталог секреты, токены с правом постоянного доступа или закрытые файлы. Для приватных файлов нужен отдельный защищённый API, выдающий краткоживущие подписанные ссылки после авторизации.
- Если CDN находится на другом домене, именно сервер CDN должен вернуть `Content-Disposition: attachment; filename=...`. Атрибут `download` для внешнего URL браузер может проигнорировать.
- V70 не загружает видео в офлайн-кеш приложения и не сохраняет его через JavaScript.
- Источники из `player-sources.js`, предоставляющие старую пару `originalFile` + `allowOriginalDownload`, продолжат поддерживаться. Для `anilist-4224` Kodik-проигрыватель подменяет базовый каталог; отдельный `licensed-downloads.json` позволит подключить разрешённые файлы независимо от него.

## Приёмочные проверки

Команда: `node --test tests/v70-download-options.cjs` из корня репозитория.

Ручная QA после добавления реального *собственного/разрешённого* файла: выбрать `watch.html?id=...` и эпизод, сравнить байтовый размер, SHA-256 и контейнер с исходником, проверить оригинал и 1080p, рабочие ссылки на ПК/Android/iOS, ошибки сети и сохранение имени файла. Плеер Kodik отдельно протестировать как **недоступный для скачивания**.
