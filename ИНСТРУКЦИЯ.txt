ПРОВЕРКА ВХОДА — НЕ ПОЛНОЕ ПОДКЛЮЧЕНИЕ ПРОФИЛЯ

1. Скопируйте account-test.html в корень AV рядом с index.html и profile.html.
2. Commit → Sync. Дождитесь публикации GitHub Pages.
3. Откройте https://anime-void-app.github.io/AV/account-test.html
4. Введите почту и пароль тестового аккаунта, созданного в Supabase Authentication → Users.
5. При успешном входе нажмите «Выйти».

Не удаляйте данные браузера. Старые файлы не заменяются.
Публичный ключ в странице допустим; секретных ключей здесь нет.
Страница обращается непосредственно к Supabase Auth по HTTPS.
Пароль не записывается в хранилище браузера кодом страницы.
Нет регистрации, восстановления пароля, синхронизации прогресса, инвентаря, платных прав.
Основная кнопка входа в мастерской пока остаётся без подключения старого backend.
Это тестовый этап: не приглашайте посетителей регистрироваться.
Реальный вход не проверен разработчиком: для него нужен ваш пароль, который передавать не следует.
