Личная редакция

Что сохранится и что попадёт в PNG

Изменения в редакторе сначала видны только в предпросмотре. Отмена оставляет сохранённое как есть. Хранятся только ID выбранных тайтлов, название, заметка и цвет. Полный JSON-бэкап включает этот частный архив; перед передачей такого бэкапа проверьте приватные данные. Для отдельной подборки есть явный экспорт PNG — без чужих постеров и скрытых списков; название, заметка и весь её выбранный состав попадут на изображение. Длинные подписи сокращаются только в PNG. Экспорт не публикует файл и не включает чужие подборки.

Неизвестные ID сохраняются без выдуманных названий. Форматы/сезоны не склеиваются. При повреждении архив не перезаписывается; при конфликте вкладок или ошибке квоты черновик остаётся. Для записи нужен Web Locks; без него можно читать и пробовать оформление.
