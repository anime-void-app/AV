ANIME VOID 17.3 — ART ATELIER
================================
Это обновление поверх установленной 17.2, не полный сайт.

ЧТО НОВОГО
• 24 лицензированные иллюстрации David Revoy / Pepper&Carrot вместо прежней коллекции.
  Это оригинальное рисованное фэнтези с влиянием манги, не кадры известных аниме и не AI-генерация.
• Исходники 2560–5689 пикселей по ширине. Файлы сайта до 2560 пикселей, WebP quality 88,
  без искусственного увеличения, плюс маленькие миниатюры для быстрой библиотеки.
• 55 прежних слотов баннеров и 41 слот фонов получили новые изображения/названия.
  Некоторые слоты — варианты кадра одной иллюстрации, а не дополнительные уникальные рисунки.
• Отдельное «Арт-ателье»: большая примерка, поиск, мои предметы, избранное,
  просмотр изображения без обрезки, кадр по двум осям, высота 180–420 px, затемнение 0–70%,
  пресеты «Кино / Панорама / Витрина». Нажмите «Применить», дождитесь сообщения о сохранении.
• Главная: новая коллекция для четырёх больших боковых карточек и галереи; вся коллекция — отдельной кнопкой.
• В ПРОФИЛЕ БОКОВЫХ АРТОВ НЕТ. Авторство и лицензии видны в интерфейсе и на art-credits.html.

ПРАВА И ПРОГРЕСС
Все 164 item ID, цены, условия открытия, состав наборов и правила наград сохранены.
Старые покупки/применённые предметы продолжают действовать: изменилась иллюстрация, а не право.
Примерка закрытого предмета не покупает/не выдаёт его. Кнопка ведёт в магазин.
Кадрирование и избранное хранятся локально в animeVoidAtelierV1 и входят в стандартный бэкап.
Вход с сохранением сессии и авторская выдача сохранены. Если SQL из прошлого архива ещё не выполнялся,
он по-прежнему нужен для авторского доступа (нового SQL это обновление не требует).
Токены входа НЕ включаются в бэкап. Платежи выключены. Облачной синхронизации профиля пока нет.

УСТАНОВКА
1. При желании сначала скачайте штатный бэкап прогресса в профиле.
2. Распакуйте ZIP. Скопируйте файлы в КОРЕНЬ вашего AV с заменой одноимённых файлов.
3. Папку studio ОБЪЕДИНИТЕ с существующей: добавится studio/atelier. Не удаляйте studio целиком.
4. Commit → Sync в правильном репозитории AV. Проверьте, что новый коммит виден на GitHub.
   Альтернатива: Add file → Upload files — файлы и папка studio с сохранением структуры,
   не ZIP и не лишняя внешняя папка «ANIME-VOID-…».
5. Дождитесь зелёного Actions, откройте профиль и нажмите Ctrl+F5.
6. Рядом с «Оформление и магазин» появится «Арт-ателье».
7. Если есть работающий отдельный backend, обновите его копию profile-catalog.json тем же файлом.

СТАРЫЕ ИЗОБРАЖЕНИЯ
В новом каталоге и галерее старые картинки больше не используются. ZIP сам не удаляет файлы на GitHub.
После установки и проверки обновления:
• можно удалить файлы вручную по УДАЛИТЬ-СТАРЫЕ-АРТЫ.txt;
• либо в ЛОКАЛЬНОЙ папке AV запустить DELETE-OLD-ARTS.cmd и ввести DELETE.
  Он вызывает delete-old-arts.ps1 и удаляет только 79 явно перечисленных старых изображений.
  Проверяет наличие нового каталога/картинок и отсутствие ссылок на старые файлы.
  Код и аватары не удаляет. Файлы БРАУЗЕРНОГО прогресса вообще не затрагиваются.
  Скрипт просмотрен, но не запускался на настоящей Windows разработчиком.
• затем зафиксируйте удаления в VS Code и отправьте их на GitHub.
Не очищайте данные сайта и не удаляйте всю папку studio!
Если обновляете только браузерной загрузкой, старые неиспользуемые файлы пока могут остаться на сервере,
но в новом оформлении они не показываются.
