ANIME VOID — сохранение сессии Supabase

1. Скопируйте в корень AV с заменой profile.html и profile-studio.js.
2. Добавьте рядом новый файл supabase-client.js.
3. Commit → Sync или Add file → Upload files на GitHub (сами три файла, не ZIP).
4. Дождитесь зелёной публикации Actions. Ctrl+F5 в профиле.
5. В мастерской войдите в аккаунт, обновите страницу: вход должен восстановиться.
6. Нажмите «Выйти», обновите страницу: аккаунт больше не должен быть подключён.

Используется локальная копия официального клиента @supabase/supabase-js 2.49.8 (MIT); CDN при открытии сайта не требуется.
Auth persistSession + autoRefreshToken, проверка пользователя через Auth API при восстановлении.
Ключ localStorage: avSupabaseAuthV1. Содержит токены сессии, НЕ пароль.
Не публикуйте содержимое этого ключа, дамп localStorage или токены. На чужом устройстве выходите из аккаунта.
Как и любое JS-хранилище, доступно скриптам того же origin: это не HttpOnly-cookie защита от XSS.
Выход отзывает текущую сессию устройства; остальные устройства не отключаются.

Прогресс, осколки, магазин и оформление остаются локальными и не загружаются в Supabase.
Регистрация посетителей, восстановление пароля, облачный профиль и платежи не включены.
Не очищайте данные сайта — потеряете локальный прогресс.
При отсутствии сети облачный вход может не восстановиться; локальный профиль остаётся доступным.

Проверено с имитатором API в Chromium: вход, восстановление после reload, refresh истёкшей сессии, выход, отсутствие входа после повторного reload, неизменность локального кошелька. Живой вход после публикации проверяет владелец.
