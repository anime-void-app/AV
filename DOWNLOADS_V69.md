# ANIME VOID V69.0 — скачивание серий в исходном качестве

## Что реализовано

На странице `watch.html` появился адаптивный блок **«Скачать серию в исходном качестве»**. Блок проверяет выбранную серию и сведения источника. Кнопка становится доступной только при явном разрешении на распространение и при наличии прямой ссылки на оригинальный файл.

Скачивание не подразумевает перекодирования, перезаписи экрана, извлечения HLS-сегментов или обхода DRM: браузер открывает исходный файл напрямую. Поддержаны разрешённые MP4, MKV, WebM, MOV, M4V, AVI.

**Важно:** сейчас в `player-sources.js` подключён внешний Kodik iframe, но отсутствуют файлы, доступные для легального скачивания. Поэтому на текущих сериях отображается сообщение о недоступности загрузки. Не выдавать этот релиз за функцию загрузки с Kodik.

## Как подключить разрешённые исходники

После получения юридического разрешения на скачивание, добавить в конфигурацию источника `window.AVVideoSources.sources` флаг и метаданные на уровне серии:

```js
{
  id: 'licensed-original-1',
  animeId: 'anilist-12345',
  type: 'mp4',
  season: 1,
  titleRu: 'Название аниме',
  titleEn: 'Anime title',
  allowOriginalDownload: true, // только с разрешения владельца прав
  episodes: [
    {
      number: 1,
      key: 's1e1',
      url: 'https://your-licensed-cdn.example/play/episode1.mp4',
      originalFile: {
        licensed: true, // разрешено распространять исходник
        original: true, // файл подтверждён источником как оригинал
        format: 'mkv',
        url: 'https://your-licensed-cdn.example/downloads/original-episode1.mkv',
        filename: 'Anime-S01E01.mkv'
      }
    }
  ]
}
```

* Все значения URL — пример схемы; домен из примера не является реальным источником.
* Сервер исходных файлов сам должен проверять право на скачивание, выдавать временные подписанные ссылки при необходимости и корректный `Content-Disposition: attachment` для загрузки в браузере. Флаги в клиентском JavaScript — только отображение, не контроль доступа.
* Кнопка `download` гарантированно применяется только к файлу с тем же origin. Внешние HTTPS-источники могут вместо загрузки открыть видео в новой вкладке, если их сервер не отдает заголовок `Content-Disposition`.
* Не включать `allowOriginalDownload` для Kodik, HLS, чужих iframe и иных ресурсов, на которые нет разрешения правообладателя.
* Для Toradora (`anilist-4224`) текущий тестовый загрузчик `av-kodik-test.js` заменяет объект `window.AVVideoSources`. Лицензированные источники для этой серии необходимо подключать в согласованной схеме загрузчика, не просто добавлять в базовый `player-sources.js`.
* Для будущего каталога может понадобиться отдельное хранилище с оплатой трафика, лицензиями и поддержкой ограничений на скачивание.

## Проверка

В рабочей копии репозитория: `node --test tests/v69-downloads-smoke.cjs`.

Ручные сценарии: открыть `watch.html?id=4224&episode=1` и убедиться, что для Kodik нет кнопки с ложной ссылкой; затем на тестовом аниме с **собственным разрешённым медиафайлом** проверить выдачу файла в исходном контейнере, размер, формат и байтовую идентичность исходнику (SHA-256), переключение серий, мобильный браузер и отказ при неподтверждённых разрешениях.

## Откат

Ветка `backup/pre-v69-original-download-20261108` хранит точку до обновления. Откатывать через отдельный revert-коммит, не переписывая более новые изменения в `main`. Права доступа и база данных V68 не изменялись.
